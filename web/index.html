First time on this device

Pointer lock, keyboard capture and clipboard need HTTPS. Import the tack certificate authority once per device:

Download tack-ca.pem

  • ChromeOS: Settings › Privacy and security › Security › Manage certificates › Authorities › Import, and trust it for websites.
  • Windows (Chrome/Edge): open the file › Install Certificate › Local Machine › Trusted Root Certification Authorities.
  • Firefox: Settings › Privacy & Security › Certificates › View Certificates › Authorities › Import.
